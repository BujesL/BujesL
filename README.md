### Projeto principal — AgentLab

**[AgentLab](https://github.com/BujesL/AgentLab)** é um projeto pessoal onde estudo, na prática, como avaliar agentes de IA de forma sistemática — ainda em estágio de MVP.

A pergunta que guia o projeto:

> **Como saber se um agente de IA está realmente pronto para produção?**

O motor testa aspectos como:

* Tool calling
* Reprodutibilidade
* Traces básicos de execução
* Métricas simples de avaliação

Uso um `ProviderAdapter` para desacoplar o motor de um provedor específico de LLM, com suporte inicial para **Mock e Ollama**. O desenvolvimento segue a metodologia Spec-Driven Development — escrever a especificação antes de implementar.
