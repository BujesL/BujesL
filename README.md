### Projeto principal — AgentLab

**[AgentLab](https://github.com/BujesL/AgentLab)** é um MVP de um framework para avaliação sistemática de agentes de IA.

O projeto busca responder uma pergunta simples:

> **Como saber se um agente de IA está realmente pronto para produção?**

O motor avalia aspectos como:

* Tool calling
* Reprodutibilidade
* Traces e observabilidade
* Métricas de avaliação
* Quality gates para CI/CD

A arquitetura utiliza um `ProviderAdapter` para desacoplar o motor de um provedor específico de LLM. Atualmente há suporte para **Mock e Ollama**, mantendo o núcleo independente do provider.

O desenvolvimento segue **Spec-Driven Development**, com especificação, contratos, implementação e testes como etapas do mesmo processo.
